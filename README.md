# 🎓 The Girls Gurukul

A fully responsive school website for The Girls Gurukul, Kalayat, Kaithal (Haryana), with modern design and AI-generated imagery.

![screenshot](IMAGE-LINK)

## ✨ Features
- Fully responsive design (mobile, tablet, laptop)
- Pages: Home, About, Academics, Admissions, Student Life, Documents and Contact
- Admissions section with an "Apply Now" button
- AI chatbot to answer visitor questions
- WhatsApp contact button
- AI-generated images

## 🛠️ Tech Used
`TypeScript` `Vercel`

## 🔗 Links
- **Live Demo:** [The Girls Gurukul](https://thegirlsgurukul-girls-gurukul-9v14.vercel.app/)

## 🚀 Run Locally
1. `git clone https://github.com/jyotichahal2005-ux/thegirlsgurukul.git`
2. `cd thegirlsgurukul`
3. `pnpm install`
4. `pnpm dev`

## 🔑 Environment Variables
Create a `.env` file for your API keys. Never upload real keys to GitHub.
